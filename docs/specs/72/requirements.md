# 72 人が依頼した課題を作るスキルを作る

対象は [Issue #72](https://github.com/paterapatera/sdd-cur/issues/72)。人が Cursor で依頼したときだけ、GitHub の課題を作るスキルを作る。

依頼が無いときに、スキルも課題ランナーも課題を作らない。作った課題は閉じない。

## 現状

課題を作るのは人である。`AGENTS.md` は、SDD スキルも課題ランナーも課題を作らない、と書いている。課題は閉じない。お客さまの確認が取れてから、人が閉じる。

課題を作らない SDD スキルは、次である。

- `skills/sdd-cur/SKILL.md`（`sdd-cur`）
- `skills/sdd-cur-implement/SKILL.md`（`sdd-cur-implement`）
- `skills/sdd-cur-quick/SKILL.md`（`sdd-cur-quick`）
- `skills/sdd-cur-fix/SKILL.md`（`sdd-cur-fix`）
- `skills/sdd-cur-complete/SKILL.md`（`sdd-cur-complete`）

`skills/sdd-cur/SKILL.md` の description は、課題の作成とクローズはしない、と書いている。

課題ランナーは課題を作らない。

`src/cli.ts` のサブコマンドは、`install`、`run`、`labels`、`candidates`、`show`、`branch`、`confirm`、`reflect`、`complete` である。課題を作るサブコマンドは無い。

`src/github.ts` の `GitHubClient` に、課題を作る操作は無い。

`install` は、`skills/` 直下のディレクトリをスキルとしてコピーする。`skills/sdd-cur-create-issue/` は、リポジトリに無い。

## 受け入れ条件

- 本課題で作るスキルは、`skills/sdd-cur-create-issue/SKILL.md` である。
- 人が内容を渡して `sdd-cur-create-issue` を明示して起動し、起動時の作業ツリーが git リポジトリであり、渡した内容から題を決められるとき、作られる GitHub の課題は 1 件である。
- その課題の題は、人が渡した内容をもとに、このスキルを実行するエージェントが決めた題である。人は題を指定しない。
- その課題の内容は、人が渡した内容である。
- その課題を作るリポジトリは、スキル起動時の作業ツリーの git リポジトリである。`gh` のカレントディレクトリのリポジトリと同じである。
- 課題を作ったあとは、作った課題の番号と URL をチャットで人に伝える。
- スキル起動時の作業ツリーが git リポジトリでないときは、課題を作らない。
- スキル起動時の作業ツリーが git リポジトリでないときは、git リポジトリでない旨を伝える。
- スキル起動時の作業ツリーが git リポジトリでないときは、止まる。
- 内容が欠けている起動では、課題を作らない。
- 内容が欠けている起動では、不足を伝える。
- 内容が欠けている起動では、止まる。
- 渡した内容から題を決められないときは、課題を作らない。
- 渡した内容から題を決められないときは、題を決められない旨を伝える。
- 渡した内容から題を決められないときは、止まる。
- 課題を作るのは、`sdd-cur-create-issue` を明示して起動し、内容を渡したときだけである。
- 依頼が無いとき、本課題で作るスキルは課題を作らない。
- 課題ランナーは、課題を作らない。
- 本課題で作るスキルが作った課題は、閉じない。
- `sdd-cur` は、課題を作らない。
- `sdd-cur-implement` は、課題を作らない。
- `sdd-cur-quick` は、課題を作らない。
- `sdd-cur-fix` は、課題を作らない。
- `sdd-cur-complete` は、課題を作らない。

## 決定

本課題で作るスキルのディレクトリ名は `sdd-cur-create-issue` である。スキルファイルは `skills/sdd-cur-create-issue/SKILL.md` である。

課題を作るリポジトリは、スキル起動時の作業ツリーが git リポジトリであるとき、そのリポジトリである。`gh` のカレントディレクトリのリポジトリと同じである。

スキル起動時の作業ツリーが git リポジトリでないときは、課題を作らない。

スキル起動時の作業ツリーが git リポジトリでないときは、git リポジトリでない旨を伝える。

スキル起動時の作業ツリーが git リポジトリでないときは、止まる。

人が渡すのは内容である。内容は、作る課題の本文である。題は人が指定しない。題は、渡した内容をもとに、このスキルを実行するエージェントが決める。

内容が欠けている起動では、課題を作らない。

内容が欠けている起動では、不足を伝える。

内容が欠けている起動では、止まる。

渡した内容から題を決められないときは、課題を作らない。

渡した内容から題を決められないときは、題を決められない旨を伝える。

渡した内容から題を決められないときは、止まる。

課題を作るのは、本スキル `sdd-cur-create-issue` を明示して起動し、内容を渡したときだけである。

人が内容を渡して本スキルを明示して起動し、起動時の作業ツリーが git リポジトリであり、渡した内容から題を決められるとき、作られる GitHub の課題は 1 件である。

課題を作ったあとは、作った課題の番号と URL をチャットで人に伝える。

## 範囲外

次は、この要件に含めない。

- 作った課題を閉じること
- 依頼が無いときの課題作成
- 本スキルを自動で起動すること
- `sdd-cur`、`sdd-cur-implement`、`sdd-cur-quick`、`sdd-cur-fix`、`sdd-cur-complete` に、課題を作る挙動を足すこと
- 課題ランナーに、課題を作る挙動を足すこと
