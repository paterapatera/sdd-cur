## REQ-789

もとになった課題は #89 である。

印がある要件ファイルでは、根拠に書いたファイルが main に無いとき、#85 の検査は失敗する。読めないときと、パスが不正で内容を得られないときも、同じ失敗である。違反は `根拠のファイルが main にありません: <パス>` である。main の読み取りは、`cmdValidate` が `git show main:<パス>` を実行することだけである。それ以外の git 操作はしない。終了コードが 0 のときは、内容を得たものとする。終了コードが 0 以外のとき、および起動できないときは、内容を得られない。

## REQ-791

もとになった課題は #89 である。

印がある要件ファイルでは、根拠の N の値が、その main 上のファイルの行数を超えるとき、#85 の検査は失敗する。判定に使うのは、十進整数として解釈した値である。違反は `根拠の行番号がファイルの行数を超えています: <パス> <N>` である。値が行数と等しいときは、失敗しない。行数は、`git show` が書いた内容の行数である。内容が空のときは 0 である。末尾が `\n` のとき、その末尾だけでは行を増やさない。
