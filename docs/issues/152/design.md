# 152 設計の決められない点を Cursor の質問機能で聞く

<!-- sdd-cur:form -->

対象は [Issue #152](https://github.com/paterapatera/sdd-cur/issues/152)。設計作成役が親への返信に残した、ファイルへ書かなかった決められない点を、SDD スキルの親が Cursor の質問機能で聞く。#39 の、列挙を人に見せて止まる手段を、この質問に置き換える。止まること、人が答えたあと設計作成役を再び起動すること、列挙が空になるまで設計レビューに入らないことは、#39 のとおり残す。

## スキルの手順

`skills/sdd-cur/SKILL.md` の `## 設計` だけを変える。frontmatter は変えない。`## 要件` は変えない。正本の文は、スキルの設計の手順へ写さない。スキルへ写すのは、下の置き換え本文だけである。囲みの外の説明は、スキルへ写さない。

置き換え本文には、列挙を人に見せて止まる、スコアに拘束力を持たせない、親がスコアの高い選択肢を選ばない、観点を質問本文に示す、の記述を入れない。

`返信の「ファイルへ書かなかった、決められない点」を読む。` の次から、`設計作成役がファイルを書いたあとも同じである。` までを、次の置き換え本文にする。置き換えの直後にある、列挙が空のときの文以降は残す。

```

設計の修正役も起動しない。
```
