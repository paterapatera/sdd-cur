## 決定

| 項目 | 内容 |
|---|---|
| 要件の合格の案内 | Cursor の質問機能で「設計に進む」と「ここで止める」。順序は要件側 SKILL 文に「この順で」を含める |
| 設計の合格の案内 | Cursor の質問機能で「実装依頼する」、「ここで止める」の順 |
| 質問の手段 | 今の `閉じる` と `閉じない` と同じ Cursor の質問機能である |
| ゲート | 根拠を示せるときは、合格の案内より先に `閉じる` と `閉じない` を出す。出し方は #114 のままである。人が選ぶまで合格の案内は出さない。`閉じる` のあとは合格の案内を出さない。`閉じない` のあと、または根拠を示せないときは、合格の案内を出す |
| 「設計に進む」 | `## 設計` の手順の先頭から入る。人が設計を依頼したときと、あとの手順は同じである |
| 「ここで止める」（要件） | その回は設計の手順に入らない。設計の作成役と設計の修正役を起動しない。設計の手順は、人が設計を依頼したときだけ始める |
