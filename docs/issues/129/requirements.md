## 関係する課題

課題は、次を関係するとする。

- #94（`request`）
- #27（作業ブランチの push と「実装依頼」）
- #46（スキルの起動条件）

#94 は、人が `request` を実行すると作業ブランチを push し、そのあと「実装依頼」を付ける、と定める。課題ランナーはこのコマンドを呼ばない。この要件は、設計の合格のあとの質問で人が「実装依頼する」を選んだときに限り、SDD スキルが `sdd-cur request <番号>` を実行する、と定める。質問での選択は、人が「実装依頼」を付けたこととみなす。push と「実装依頼」の付与の中身は、#94 のコマンドのままである。このコマンドを呼ぶのは、その選択のときだけである。要件の合格のあとの質問は、`request` を実行しない。「ここで止める」を選んだとき、push と「実装依頼」は人が行う。

#27 は、人は要求と設計を含む作業ブランチを push してから「実装依頼」を付ける、と定める。push も「実装依頼」も人が行う。この要件の「ここで止める」は、その定めのままである。「実装依頼する」を選んだときは、`sdd-cur request <番号>` が push のあと「実装依頼」を付ける。質問での選択は、人が「実装依頼」を付けたこととみなす。

#46 は、`sdd-cur` をコマンドで指定したときだけ手順に入る、と定める。この要件は、その起動条件を変えない。質問は、すでに手順に入ったあとの、合格の案内である。
