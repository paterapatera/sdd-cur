# 119 導入先の既存コードから方針ファイルの下書きを作る

対象は [Issue #119](https://github.com/paterapatera/sdd-cur/issues/119)。人が明示して起動したときだけ、導入先のコード、README、パッケージ定義を読み、`docs/policy.md` の四節の下書きを作るスキルを足す。

## 関係する課題

課題は、次を関係するとする。

- #118（導入先に方針のひな形を置く `init`）
- #84（方針を一つのファイルにまとめる）
- #90（調べるだけの段）

#118 は、`docs/policy.md` が無いときだけ、`policyTemplate` のひな形を置く。既にあるファイルは上書きしない。この要件は、`init` と `policyTemplate` を変えない。ひな形だけのファイルへ四節の下書きを書くのは、`init` ではなく、この課題のスキルである。

#84 は、誰のための道具か、技術の前提、構成、破ってはいけない原則を、一つの方針ファイルにまとめる。この要件は、下書きの節をその四つにする。このリポジトリの `docs/policy.md` は書き換えない。

#90 は、調べるだけの段がファイルを書かない、と定める。この要件は、その段と `agents/sdd-cur-explore.md` を変えない。下書きを書くのは、別のスキルである。

## 範囲外

次は、この要件に含めない。

- 方針の自動更新や定期実行
- このリポジトリの `docs/policy.md` の書き換え
- `init` のひな形を変えること（#118）
- 調べるだけの段がファイルを書くこと（#90）
