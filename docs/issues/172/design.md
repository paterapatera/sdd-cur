## 範囲外

- 人が `sdd-cur-create-issue` を明示して起動していないときに、課題を作ること
- 分割案の形でない内容で、課題を 2 件以上作ること
- 分割案の形でないときに、タイプを聞き、そのタイプの質問を一問ずつ聞いてから 1 件作る手順を変えること
- ユーザーストーリー、修正、機能改善、調査の見出しの文言または順を変えること
- 元の課題へコメントを投稿すること
- 元の課題のラベルを変えること
- 元の課題に担当者を付けること
- 作った課題を閉じること
- #171 の分割案の行の形を変えること
- `src/cli.ts` の `show` の JSON の形を変えること
- `agents/` を変えること
- `skills/sdd-cur/SKILL.md` を変えること
- 依存パッケージを足すこと
- `docs/policy.md` と AGENTS.md を変えること

## 関係する課題

- #171（分割案の書式と SDD スキルからの渡し方）
- #143（課題タイプ、質問、見出し、一件作成の手順）

#171 は分割案の形を定め、人が `sdd-cur-create-issue` に分割案を渡して起動すれば子の課題を作れる、と伝える。本課題は、その起動時の `sdd-cur-create-issue` の手順を足す。`docs/issues/171/` は書き換えない。

#143 は分割案でないときの一件作成を定める。本課題は、分割案のときの分岐と複数件作成を足す。一件の質問一覧と見出しは変えない。`docs/issues/143/` は書き換えない。

## 決定

| 項目 | 内容 |
|---|---|
| 分割案の形 | 渡した内容の非空行が、行全体が `分割案:` の一行と、子の行が二行以上だけであるときである。子の各行は、行全体が `- <番号>. 題: <題> 受け入れ条件: <番号の列> 依存: <依存>` と一文字も違わない。`<番号>` は 1 から始まり 1 ずつ増え、子の行数と一致する。`<題>` は空白以外の文字を含む。`<番号の列>` は、番号が一つのときはその番号だけ、二つ以上のときは昇順で `1, 3, 5` のとおりカンマと空白で区切る。上記を満たさないときは、分割案の形ではない。#143 の一件作成へ進む |

### 分割案のときの質問の順

起動時の作業ツリーが git リポジトリであるとき、分割案の形と判定したあとの順は次である。`gh issue create` より前に行う。

1. 元の課題の番号を、決定の表のとおり聞く。
2. `bun src/cli.ts show <番号>` を実行し、仕様ファイルを読む。
3. タイプを五択で聞く。`一件ずつ選ぶ` のときは、件ごとに四択でタイプを聞く。
4. 件ごとに本文を組み立てる。埋められない節だけ、#143 と同じ質問文をそのタイプの一覧の順に一問ずつ聞く。
5. 全件の題と本文を人に見せ、承認を得る。

git リポジトリでないときは、1 の前に #143 と同様に止まる。

### 見出しごとの埋め方

子の `受け入れ条件` に挙がる設計の受け入れ条件の行を、番号の昇順に並べる。各行から `条件:` の直後から ` 主体:` の直前までを条件部、`主体:` の直後から ` 結果:` の直前までを主体部、`結果:` の直後から行末までを結果部とする。節の本文は、スペースと改行以外の文字を含む文字列である。埋められないときは、その節は空であり、#143 の質問で埋める。

共通:

- `## 重なる課題`: 決定の表のとおり。一件作成の答え形式を維持する。
- `## 背景`: `requirements.md` に行全体が `## 現状` である見出しがあれば、その節の本文。無いときは `design.md` の `#` 見出し行の次の行から、次の行頭が `## ` である行の直前まで。

ユーザーストーリー:

- `## ユーザーストーリー`: 条件部が一つだけのときはその条件部。二つ以上のときは、番号がいちばん小さい行の条件部、改行、番号が二番目に小さい行の結果部。三つ以上のときは、番号がいちばん小さい行の条件部、改行、二番目の結果部、改行、三番目以降は各行の結果部を改行で連結する。
- `## 手を入れる対象`: `design.md` に行全体が `## 変えるファイル` である見出しがあれば、その節の本文。無ければ、各行の主体部を改行で連結する。
- `## 比べる相手`: `requirements.md` に `比べる相手` を含む行頭が `## ` である見出しがあれば、その節の本文。無ければ埋められない。

修正:

- `## 失敗していること`: 各行の条件部を改行で連結する。
- `## 失敗する手順`: 各行の主体部を改行で連結する。
- `## 期待する結果`: 各行の結果部を改行で連結する。

機能改善:

- `## 今の挙動`: 各行の条件部を改行で連結する。
- `## 変えたいこと`: 各行の結果部を改行で連結する。
- `## 変えないこと`: `design.md` に行全体が `## 範囲外` である見出しがあれば、その節の本文。無ければ埋められない。
- `## 手を入れる対象`: ユーザーストーリーと同じ。
- `## 比べる相手`: ユーザーストーリーと同じ。

- `## 調べる範囲`: 各行の主体部を改行で連結する。
- `## 調べ終わり`: 各行の結果部を改行で連結する。
