# 18 マージ時にブランチを削除する

対象は [Issue #18](https://github.com/paterapatera/sdd-cur/issues/18)。完了処理がマージするときに、そのブランチも削除する。

分割元は #16 である。#16 の該当項目も、マージするときにブランチも削除することである。

#7 の完了処理は、マージリクエストのスカッシュマージと「マージ済み」を行う。ブランチの削除は、#7 と #2 の範囲外だった。この要件は、そのマージのときにブランチを削除することを足す。

## 受け入れ条件

- 完了処理がスカッシュマージするとき、マージしたブランチも削除する。
- 課題ランナー経由と完了スキル経由の両方で、同じ完了処理がこの削除を行う。
- 課題は閉じない。

## マージと削除

スカッシュマージは完了処理だけが行う。完了処理は、課題ランナーと、Project A の Cursor で人が起動する完了スキルの、両方から呼ぶ。

完了処理がマージリクエストをスカッシュマージするとき、そのヘッドであるブランチを削除する。

課題は閉じない。お客さまの確認が取れてから、人が閉じる。

## 範囲外

次は、この要件に含めない。

- すでにマージ済みのマージリクエストを、もう一度マージしないこと（#7）
- 「マージ済み」を付けること（#7）
- 一つのプロジェクトで、課題ランナーと完了スキルを同時には有効にできないこと（#7）
- 「動作確認OK」を付けること。付けるのは人である
- 「実装依頼」から「実装完了」まで。受け入れ手順のコメント（#6）
- 課題の作成とクローズ
- 着手、要件、設計、確認、回答の取り込み
- フォーク、レビュー依頼、ドラフト（#2）
- Forgejo、Jira、Backlog
