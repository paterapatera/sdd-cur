# 93 設計のテスト節の実行を、実装レビュー役の外に出す

対象は [Issue #93](https://github.com/paterapatera/sdd-cur/issues/93)。設計の「テスト」節の実行を、実装レビュー役の外へ出す。実行する主体は、`sdd-cur-implement` を実行している親である。親は、レビュー役を起動する前に実行し、起動した各コマンドの終了コードと出力をレビュー役に渡す。レビュー役は、渡された結果を読んで判定する。レビュー役は実行しない。

実行すべき記述の決め方は、#40 のままである。失敗の決め方も、#40 のままである。実行の場所は、作業ツリーのままである。

## 受け入れ条件

- 実行すべき記述がある「テスト」節があるとき、親は、実装レビュー役を起動するたびに、その起動より前に実行する。
- 実行すべき記述がある「テスト」節は、書かれた順に実行する。
- 実行すべき記述がある「テスト」節は、すべて実行する。
- 一つの節の実行で、終了コードが 0 以外のコマンドがあっても、残りの節を実行する。
- 実行すべき記述は、バッククォートまたはコードフェンスの中のコマンド行と、明示的な手順の箇条書きである。
- 実行すべき記述以外の文は、実行しない。
- 実行すべき記述が無い「テスト」節は、実行しない。
- 「テスト」節が無いときは、実行しない。
- 実行する主体は、実装の agent の親である。課題ランナーは実行しない。
- 親は、起動した各コマンドの終了コードを、実装レビュー役に渡す。
- 親は、起動した各コマンドの出力を、実装レビュー役に渡す。
- 実装レビュー役は、判定のとき、渡された終了コードと出力を読む。
- 終了コードが 0 以外のコマンドがあるとき、その結果は、実装の指摘である。
- 終了コードが 0 のコマンドは、失敗ではない。
- 終了コードが 0 以外でも、親は、レビュー役の起動を省かない。
- 実行したコマンドが無いことだけでは、実装レビューは不合格にしない。
- 実装レビュー役は、設計の「テスト」節を実行しない。
- 実行の省略によるやり直しの手順は、無い。
- レビュー役向けの、一時ディレクトリと既存のテスト用一時ファイルを触ってよいとする例外規定は、無い。

- 実装レビュー役の `readonly` の説明は、一時ディレクトリと既存のテスト用一時ファイルの例外規定を含まない。

## 実行

親が行う。レビュー役は行わない。課題ランナーは行わない。

実行すべき記述は、バッククォートまたはコードフェンスの中のコマンド行と、明示的な手順の箇条書きである。それ以外の文は実行しない。実行すべき記述が無い節は実行しない。節が無いときは実行しない。

実行すべき記述がある節は、書かれた順にすべて実行する。一つの節の失敗で、残りの節を飛ばさない。

失敗は、起動したコマンドの終了コードが 0 以外である。終了コードが 0 のコマンドは、失敗ではない。終了コードが 0 以外のコマンドが一つでもあるとき、その実行は失敗であり、実装の指摘である。そのときも、親は残りの節を実行し、レビュー役を起動する。

実行の場所は、作業ツリーである。

設計の「テスト」節に書かれた実行が禁止と矛盾するときは、その節に書かれた実行を優先する。優先するのは、その節の範囲だけである。節の外では、禁止のとおりである。この優先でも、レビュー役の `readonly: true` は外さない。親は外さない。実装の意図的な編集はしない。ここでいう禁止は、レビュー役に書いた禁止と、スキルの `## 禁止` である。

### 毎回のレビュー

- 設計の「テスト」節を実行しない。渡された終了コードと出力を読む。実行していない節を探して不合格にしない。
- 失敗は、渡された終了コードが 0 以外である。終了コードが 0 のコマンドは、失敗ではない。実行したコマンドが無いことだけでは、失敗ではない。

不合格の回数の段落から、`テスト節の実行省略だけのやり直しでは増やさない。` を消す。印が壊れているやり直しでは増やさないこと、手順未網羅だけの不合格も増やすこと、モデルの文言は残す。

実行の省略によるやり直しの塊は、次の八行である。この八行を消す。同じ文言が他にある行は、この八行ではないので消さない。実行の省略によるやり直しは、置かない。

```
判定行が `判定: 不合格` のとき、レスポンスに「実装の指摘なし」とあり、実行すべき記述がある見出し `テスト` の節の実行省略だけがあるときは、回数は増やさない。
手順未網羅ではない。
修正役は起動しない。
親は手順本文を書き直さない。
同じレビューをもう一度起動する。
モデルは、その数えるレビューと同じである。
戻ったレビューでも、実行すべき記述がある「テスト」節は、レビュー役が、書かれた順にすべて実行する。
一つの節の失敗で、残りの節を飛ばさない。
```

その八行の直後の一文を、次の一行にする。10 回の打ち切りの文は残す。

```
判定行が `判定: 不合格` のときは、回数を 1 増やす。
```

修正のあとの `戻ったレビューでも、実行すべき記述がある「テスト」節は、レビュー役が、書かれた順にすべて実行する。` は、`戻ったレビューでも、実行すべき記述がある「テスト」節は、親が、レビュー役の起動より前に、書かれた順にすべて実行する。` にする。その直後に、`レビュー役は実行しない。` と、`親は、各コマンドの終了コードと出力を渡す。` を足す。その戻りにある `一つの節の失敗で、残りの節を飛ばさない。` と、`失敗は、起動したコマンドの終了コードが 0 以外である。` は残す。

手順本文を書き直す段落の `テスト節の実行省略が同時にあっても、同じである。` は消す。`実行すべき記述がある「テスト」節は、毎回、書かれた順にすべて実行する。` は、`実行すべき記述がある「テスト」節は、親が、レビュー役の起動より前に、毎回、書かれた順にすべて実行する。` にする。その直後に、`レビュー役は実行しない。` と、`親は、各コマンドの終了コードと出力を渡す。` を足す。`節が無いとき、または実行すべき記述が無いときは、実行を省略する。` は、`節が無いとき、または実行すべき記述が無いときは、実行しない。` にする。その段落の `一つの節の失敗で、残りの節を飛ばさない。` は残す。
