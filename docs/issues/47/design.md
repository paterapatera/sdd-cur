# 47 作成役は仕様の全文を返信せずパスを返す。。

対象は [Issue #47](https://github.com/paterapatera/sdd-cur/issues/47)。要求作成役と設計作成役は、書いた仕様ファイルの全文を親へ返している。仕様が長いとき、同じ全文がレビューと修正のたびに会話に残る。作成役は、リポジトリルートからの相対パスと、当該起動で変えた節だけを返す。親は、作業ツリー上のファイルを読む。

重なる課題は無い。

## 受け入れ条件

- `agents/sdd-cur-req-author.md` の `## 親への返信` は、書いたファイルの全文を求めない。この節に `書いたファイルの全文` は無い。
- `agents/sdd-cur-design-author.md` の `## 親への返信` は、書いたファイルの全文を求めない。この節に `書いたファイルの全文` は無い。
- 要求作成役と設計作成役の返信には、当該起動で書いた仕様ファイルの、リポジトリルートからの相対パスを含める。ファイルを書いていないときは、パスは含めない。
- 要求作成役と設計作成役の返信には、当該起動で新規に書いた、または本文を変えた節だけを含める。変えていない節の本文は含めない。ファイルを書いていないときは、節は含めない。
- 要求作成役は、質問する未記載と、依存または保留のため質問しない未記載を返す。
- 設計作成役は、ファイルへ書かなかった、決められない点を返す。
- `skills/sdd-cur/SKILL.md` の「要件」と「設計」は、作成役の返信から仕様の全文を読まない。仕様の内容を確認するときは、作業ツリー上のパスからファイルを読む。
- 要求のレビュー役、設計のレビュー役、要求の修正役、設計の修正役が、差分だけを返す扱いは変えない。
- 実装作成役の親への返信は、この設計の対象に含めない。
