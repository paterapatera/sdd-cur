明示して起動していないときは、課題を作らない。依頼が無いときは、課題を作らない。起動時の作業ツリーが git リポジトリでないときは、課題を作る前にそれを見て、どのタイプの課題を作るかを人に聞くより前に止まる。課題を作らない。git リポジトリでない旨を伝える。`gh issue create` は実行しない。本文用の内容がスペースと改行以外の文字を含み、渡した内容から題を決められないときは、先に git リポジトリでない旨を伝え、次に題を決められない旨を伝える。カレントディレクトリは、起動時の作業ツリーのままである。`--repo` は付けない。ラベル、担当者、マイルストーンは付けない。対話の編集はしない。認証は `gh` のログインに任せる。トークンも環境変数も読まない。分割案の形でないときに課題が 1 件できたとき、その番号と URL をチャットで人に伝える。伝えたあとは止まる。課題を閉じない。
