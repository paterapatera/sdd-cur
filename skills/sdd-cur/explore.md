## 調べる

人が調査を依頼したときだけ、調べるだけの段を行う。
人が調査を依頼していないときは、調べるだけの段を行わない。
人が課題番号を決めたあとだけ行う。
課題番号が無いときは、調べるだけの段を行わない。
`sdd-cur gate <番号> explore` を実行し、終了コードが 0 以外なら止まる。
`allowed` が `false` なら `reason` を伝えて止まる。
`allowed` が `true` なら、続けて `sdd-cur show <番号>` を実行し、終了コードが 0 以外なら止まる。
`allowed` が `true` のときだけ、サブエージェントを一つ起動する。
起動する名前は `sdd-cur-explore` である。
`model` は渡さない。
frontmatter の `model` を使う。
起動するときに、課題番号と、人が依頼した調査の内容と、`show` が返した課題本文とコメントを渡す。
この段はファイルを書かない。
この段は課題コメントを書かない。
この段はラベルを変えない。
作業ブランチは用意しない。
