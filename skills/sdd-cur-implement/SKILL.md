# sdd-cur-implement

## 実装

プロンプトのスキル名のあとにある課題番号と絶対パスを使う。`docs/specs/<番号>/requirements.md` と `docs/specs/<番号>/design.md` を読み、その設計の受け入れ条件、決定、範囲の中だけを作業ツリーへ実装する。受け入れ手順の本文は、渡された絶対パスへ書く。印の行は書かない。

## 禁止

課題を作らない。課題を閉じない。ラベルを変えない。コミットしない。push しない。マージリクエストを作らない。スカッシュマージしない。コメントを投稿しない。`gh` を直接起動しない。
